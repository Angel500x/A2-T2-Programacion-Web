## Instalación
Para utilizar **Utileria.js**, se debe tener el archivo `utileria.js`, y colocarlo en el proyecto dentro de `/js` e impórtalo en el `<head>` del html o antes de cerrar el `</body>`:
```html <script src="js/utileria.js"></script>```
